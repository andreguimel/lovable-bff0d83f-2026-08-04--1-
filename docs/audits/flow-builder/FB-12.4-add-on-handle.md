# FB-12.4 · Add-on-handle (+) + Mini-palette contextual

Status: **ENCERRADA** · Escopo: paridade UX BotConversa (criação rápida a partir da saída de um bloco).

## Objetivo
Permitir criar o próximo bloco diretamente a partir de qualquer saída válida — sem arrastar da Library nem abrir Command Palette — preservando os métodos anteriores.

## Alterações

| Arquivo | Papel |
| --- | --- |
| `src/features/flow-builder/canvas/v3/AddOnHandle.tsx` (novo) | Wrapper do `PillHandle`; injeta botão `+` discreto em cada saída e ancora a mini-palette. |
| `src/features/flow-builder/canvas/v3/MiniPalette.tsx` (novo) | Popover em Portal, busca auto-focada, agrupamento canônico, Recentes, filtragem por `HIDDEN_KINDS`. |
| `src/features/flow-builder/canvas/v3/BlockNodeV3.tsx` | Todas as saídas (single, condição true/false, opções de Menu, rotas do Randomizer) passam por `AddOnHandle` com `nodeId` + `handleId`. |
| `src/features/flow-builder/canvas/v3/v3.css` | Estilos do `+` (hover/focus, cor da categoria) e do popover (elevação, layout, linhas com ícone). |
| `src/features/flow-builder/__tests__/add-on-handle.test.ts` (novo) | Cobertura de contrato + round-trip. |
